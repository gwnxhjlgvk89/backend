# 管理员操作说明

1. 使用学校分配账号登录；首次登录先修改密码。学生只能操作自己的资料、收藏与报名。
2. 普通管理员可分页查询学生、维护学生/社团、预览并确认导入、生成私有导出。超级管理员另外管理管理员权限和活动配置。
3. 名单导入为 XLSX，列名固定：`username,name,major,class_name,password,reserved_club_id`。密码至少10字符、UTF-8不超过72字节；学号列设为文本以保留前导零。预报名列填写稳定数字社团ID，可为空。
4. 先上传→等待预览→核对数量、样例和预报名资格→确认导入。重复账号、专业不符、名额不足会拒绝；应用时发生冲突整批回滚。任务列表可在重新登录后找回。导出文件仅任务创建人可下载。
5. 社团总名额包含预报名，学生默认只占一个名额。已有普通报名不能直接改成预报名。删除有报名的社团会被拒绝。
6. 活动输入完整北京时间，例如 `2026-10-01 09:00`。开始包含、结束不包含。退选是否允许、截止时间由超级管理员设置；预报名默认不能自行退选。
7. 活动正式开放期间，名单、资格、名额和报名结果不可修改，导入/重型导出不可执行。维护时超级管理员先暂停，核对后恢复。
8. 发布前会检查时间、社团、名额一致性及已有报名资格。报名期间不要频繁调整活动状态。
9. 学生网络中断看到“结果确认中”时，先查询自己的报名；后台 MySQL 记录是最终依据。未收到推送不代表报名失败。
10. 换届重置通过专门维护工具，不放在容易误点的学生管理页；需要超级管理员验证、数量预览、匹配的备份和恢复演练凭证。

上线前还需确认微信后台的用户隐私保护指引与当前实际收集项一致（账号、报名资料、用户主动设置的联系方式/头像），并完成 iOS/Android 真机验收。
